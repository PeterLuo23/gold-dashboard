🔗半导体供应链

8/4重大更新：
• 光模块/CPO：1.6T光模块技术突破+英伟达供应链订单回暖预期，CPO板块暴力反弹。中际旭创、新易盛、天孚通信单日涨超13%，主力净流入合计超125亿。但需警惕：上月CPO市值蒸发2.6万亿，今日反弹是否为"下跌中继"仍需观察。
• PCB：AI服务器PCB需求爆发，东山精密、沪电股份、深南电路等20余股涨停。元件行业净流入147.50亿，仅次于通信设备。
• 存储：SK海力士×闪迪发布HBF标准，兆易创新+4.48%，存储板块情绪修复。但传统DRAM/NAND需求仍疲软，HBM是结构性亮点。
• 国产替代：《集成电路布图设计保护条例》修订+中芯国际港股+5%，国产设备材料逻辑强化。北方华创、中微公司等Q2业绩超预期标的或持续受益。
• 结论：半导体从"8/1恐慌抛售"到"8/4暴力修复"仅用3天，情绪切换极快。短期看，光模块/PCB是资金主攻方向；中期看，国产替代+AI算力仍是核心逻辑。

链条① 光模块/CPO：技术突破+订单预期 → 资金暴力回补 → 涨停潮

互验：1.6T光模块技术突破（产业）✓ + 英伟达供应链回暖（事件）✓ + 通信设备主力+222亿（资金）✓ = 三因素共振。矛盾点：上月市值蒸发2.6万亿，基本面是否支撑V型反转？机构观点分歧。操作：龙头（中际旭创/新易盛/天孚通信）已暴涨，追高需谨慎；关注PCB/液冷等补涨方向。

链条② CXO/创新药：药明康德业绩超预期 → 板块集体暴动

互验：营收+38.93%/净利+29.43%（业绩）✓ + 港股药明康德+11.17%（映射）✓ + 医疗服务主力+28.70亿（资金）✓。逻辑：CXO板块经历长期估值压缩后，业绩超预期触发估值修复。操作：药明康德已涨停，关注凯莱英、康龙化成等跟涨标的的持续性。

链条③ 高低切换：高股息防御（银行/白酒）失血 → 科技成长吸血

互验：银行-45亿（资金）✓ + 白酒-33亿（资金）✓ + 创业板+5.64%（指数）✓ = 资金从防御切向成长的极致演绎。历史规律：高低切换往往持续3-5个交易日，随后分化。操作：若持有高股息仓位，不宜在杀跌时割肉；科技仓位需设好止盈，防止次日分化。

链条④ A股情绪：8/1恐慌 → 周末非农 → 8/3美股反弹 → 8/4 A股暴力修复

互验：美股反弹提供情绪支撑 ✓ + 政策利好（集成电路条例）✓ + 业绩催化（药明康德）✓。矛盾点：单日涨幅过大（创业板+5.64%），获利盘丰厚，次日抛压风险高。操作：暴涨次日不追涨，等分化后找真龙头低吸。
